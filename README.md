# starthome-marketing

스타트홈 인스타그램 **게시용 임시 공개 저장소**입니다.
인스타 API는 공개 URL에서 이미지·영상을 받아가므로, 게시 직전에 여기에 올리고 게시가 끝나면 지웁니다.

- 원본 보관처가 아닙니다. 카드 원본은 `starthome-vault/30_기획/콘텐츠 자동발행/`, 영상 원본은 Drive/S3에 둡니다
- 개인정보가 들어간 파일은 올리지 않습니다 (공개 저장소). 현장 사진은 사용 동의가 끝난 것만, 인물·실명·주소·비밀번호 스티커가 보이지 않는 컷만 올립니다 (2026-10-18 대표 결정)

## 구조

```
cards/YYYY-MM/<slug>/01.png … 06.png   # 카드뉴스 (1080×1350 또는 1080×1080)
reels/YYYY-MM/<slug>.mp4               # 릴스 (9:16, H.264+AAC, 90초 이하, 100MB 미만)
blog/YYYY-MM-DD-<slug>/post.md         # 네이버 블로그 패키지 (meta.json, images/01.jpg …). 대표가 Claude in Chrome으로 붙여 발행
```

블로그 패키지는 게시 뒤에도 지우지 않는다(발행 기록). 규격은 vault `30_기획/콘텐츠 자동발행/블로그 패키지 템플릿/README.md`.

## 게시 흐름

1. Slack `#카드뉴스-승인`에서 ✅ 확인
2. 파일을 위 경로에 커밋·푸시 → 공개 주소 `https://raw.githubusercontent.com/dnsi37/starthome-marketing/main/<경로>`
3. 인스타 API로 게시 (영상은 처리 완료 확인 후)
4. 게시 완료가 확인되면 파일 삭제 커밋

## 규칙

- 파일 하나 100MB 미만 (GitHub 한도). 영상이 월 10개를 넘으면 영상만 S3로 옮긴다
- 파일명은 영문·숫자·하이픈만. 한글 파일명은 URL 인코딩 문제가 생긴다
- 삭제해도 git 이력에는 남으므로, 올리기 전에 "공개돼도 되는 파일인가"를 먼저 본다
